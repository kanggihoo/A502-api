# 10. Get a public file

## 기본 정보
- **기능**: 로그인 없이 공개 링크(파일 해시)를 통해 파일을 조회한다.
- **Endpoint**: `GET /files/{file_id}/public`
- **인증**: 불요 (공개 링크를 통한 접근)
- **권한**: 권한 불요 (No permissions required)

## 설명
파일 ID와 파일 해시(`h`)를 이용해 로그인 없이도 접근 가능한 공개 파일을 조회한다. Mattermost에 인증되지 않은 사용자도 올바른 해시 값만 있으면 파일에 접근할 수 있다. 해시가 일치하지 않거나 파일이 존재하지 않는 경우 오류가 반환된다.

## Request

### Path parameters
| 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|
| file_id | string | Yes | 조회할 파일의 ID |

### Query parameters
| 이름 | 타입 | 필수 | 설명 |
|---|---|---|---|
| h | string | Yes | 파일 해시 |

## Response

(성공 시 파일 콘텐츠가 직접 반환되며, 별도의 JSON 스키마는 문서에 명시되어 있지 않음)

## Errors
| 상태 코드 | 설명 |
|---|---|
| 400 | 명시되지 않음 |
| 401 | 명시되지 않음 |
| 403 | 적절한 권한이 없음 |
| 404 | 명시되지 않음 |
| 501 | 명시되지 않음 |

```json
{
  "status_code": 0,
  "id": "string",
  "message": "string",
  "request_id": "string"
}
```

## 주의 사항
파일 해시(`h`)가 올바르지 않으면 403 오류가 발생한다. 이 엔드포인트는 다른 파일 관련 엔드포인트(`/api/v4/files/...`)와 달리 API 버전 프리픽스가 없는 `/files/...` 경로를 사용한다.
