# _86-time-tracking API 요약

이 리소스 그룹은 Jira의 시간 추적(Time Tracking) 제공자 선택 및 시간 추적 옵션(기본 단위, 시간 형식, 주당 근무일/일당 근무시간)을 조회·설정하는 사이트 전역 설정용 API 5개로 구성되어 있다.

## 제외된 API

- `01-get-selected-time-tracking-provider-get.md`: "Administer Jira" 글로벌 권한(사이트 전체 관리자) 필요 — 교육생(프로젝트 관리자) 권한으로는 호출 불가.
- `02-select-time-tracking-provider-put.md`: "Administer Jira" 글로벌 권한(사이트 전체 관리자) 필요 — 교육생(프로젝트 관리자) 권한으로는 호출 불가.
- `03-get-all-time-tracking-providers-get.md`: "Administer Jira" 글로벌 권한(사이트 전체 관리자) 필요 — 교육생(프로젝트 관리자) 권한으로는 호출 불가.
- `04-get-time-tracking-settings-get.md`: "Administer Jira" 글로벌 권한(사이트 전체 관리자) 필요 — 교육생(프로젝트 관리자) 권한으로는 호출 불가.
- `05-set-time-tracking-settings-put.md`: "Administer Jira" 글로벌 권한(사이트 전체 관리자) 필요 — 교육생(프로젝트 관리자) 권한으로는 호출 불가.

이 리소스 그룹의 모든 API가 제외되어, 채택된(우선순위 접두사가 붙은) API는 없다.
